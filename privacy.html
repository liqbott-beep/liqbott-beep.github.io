Privacy Policy

liqchannel and Day Counter · Last updated October 3, 2026

Who this covers

liqchannel is a private publishing tool used only by the owner of Day Counter for the owner's own YouTube, TikTok and Instagram accounts. It is not a public service and does not let anyone else sign in. Viewers who watch Day Counter content on those platforms are covered by each platform's own privacy policy; this app collects nothing about them beyond the aggregate statistics described below.

YouTube (Google) data

Using YouTube API Services, the app accesses the owner's own YouTube channel to:

  • upload videos and thumbnails, and set their titles, descriptions and publish times;
  • delete videos the owner rejects before publishing;
  • read view, watch-time, retention and subscriber statistics for the channel's own videos.

It does not access any other user's data, email, contacts or files. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using it you agree to the YouTube Terms of Service; Google's handling of data is described in the Google Privacy Policy. Access can be revoked at myaccount.google.com/permissions.

TikTok data

With the owner's authorization (scopes user.info.basic, video.publish and video.list), the app reads the owner's TikTok display name, posts short video clips to the owner's own account, and reads view, like, comment and share counts for those posts. It does not access other TikTok users' data. Access can be removed in the TikTok app under Settings and privacy > Security > Manage app permissions.

Instagram (Meta) data

With the owner's authorization (instagram_business_basic, instagram_business_content_publish and instagram_business_manage_insights), the app reads the owner's account ID and username, publishes Reels to the owner's own professional account, and reads insights (views, likes, comments, shares, saves) for those Reels. It does not access other Instagram users' data or messages. Access can be removed in Instagram under Settings > Website permissions > Apps and websites.

How data is used and stored

Statistics are used only to decide which topics, titles and clips to make next. Access tokens are stored as encrypted secrets in a private GitHub repository controlled by the owner; aggregate post statistics are kept in that same private repository. No data is sold, shared with third parties, or used for advertising.

Deletion

Revoking access on any platform stops all further access immediately. On request to the contact below, stored statistics are deleted within 30 days.
